# ONDO° 온도컴퍼니 — 공식 사이트

**ONDO = ON + DO — "온라인에서 되게 만든다"**

세 가지 서비스(온도 웹 · 온도 클립 · 온도 AI)를 첫 화면에서 한 번에 보여 주고,
각 서비스마다 상세 페이지와 요금·작업물로 연결되는 멀티페이지 정적 사이트입니다.

**세 서비스는 순서가 있는 단계가 아니라 각각 독립된 상품입니다.**
사이트 문구도 그 기준으로 통일해 두었습니다 — "필요한 것만 고르시면 됩니다".
카피를 고치실 때 "웹부터", "그다음", "웹이 있어야" 같은 표현이 들어가지 않게 주의해 주세요.
빌드 도구·프레임워크 없이 순수 HTML/CSS/JS라, 파일을 그대로 올리면 바로 동작합니다.

## 2. GitHub Pages 배포

저장소는 이미 만들어 두셨다고 하셨으니, **이 폴더 안의 내용물 전체**를 저장소 루트에 올리시면 됩니다.
(`ondo-site` 폴더째로 올리면 주소가 한 단계 깊어집니다. 폴더를 열고 **안에 있는 것들**을 올려 주세요.)

### 웹에서 올리는 방법
1. 저장소 페이지 → **Add file → Upload files**
2. 이 폴더 안의 파일·폴더를 전부 끌어다 놓기
3. 아래 **Commit changes** 클릭
4. 저장소 **Settings → Pages** → Source를 **Deploy from a branch**, 브랜치 `main` / 폴더 `/ (root)` → **Save**
5. 1~2분 뒤 `https://<아이디>.github.io/<저장소이름>/` 으로 열립니다

### 명령어로 올리는 방법
```bash
cd ondo-site
git init
git add .
git commit -m "ONDO 사이트 첫 배포"
git branch -M main
git remote add origin https://github.com/<아이디>/<저장소이름>.git
git push -u origin main
```

> `.nojekyll` 파일이 없으면 `assets/` 같은 폴더가 무시될 수 있습니다. 이미 넣어 두었으니 지우지 마세요.

## 3. 배포한 다음 반드시 바꿀 것

### ① 사이트 주소 (제일 중요)
지금은 임시 주소가 들어가 있습니다. 실제 주소가 나오면 **전체 찾아 바꾸기**로 한 번에 교체하세요.

- 찾을 문자열: `https://REPLACE-ME.github.io/ondo/`
- 바꿀 문자열: 실제 주소 (예: `https://hyunjun.github.io/ondo/`) — **끝의 `/`까지 포함**
- 들어 있는 파일: 모든 `.html`, `robots.txt`, `sitemap.xml`

이걸 바꿔야 카카오톡·구글에 링크를 보냈을 때 미리보기 이미지가 제대로 뜹니다.

### ② 문의폼 수신 주소
지금은 폼을 제출하면 **“카카오톡으로 연락 주세요”** 안내가 뜨도록 처리되어 있습니다.
실제로 이메일로 받으시려면:

1. [formspree.io](https://formspree.io) 가입 → 새 폼 생성 → 발급된 주소 복사
2. `contact/index.html`에서 `https://formspree.io/f/REPLACE_FORMSPREE`를 그 주소로 교체

교체하는 순간 자동으로 실제 전송으로 바뀝니다. (무료 플랜 월 50건)

### ③ 사업자 정보 (사업자 등록 후)
모든 페이지 아래쪽 푸터에 주석 처리된 블록이 있습니다. `<!--` 와 `-->` 를 지우고 값을 채우세요.

### ④ 전화·이메일 공개 (원하실 때)
`contact/index.html`에 주석 처리된 블록이 있습니다. 주석을 풀고 번호·이메일을 채우면 복사 버튼까지 같이 동작합니다.
**지금은 가짜 번호를 노출하지 않으려고 일부러 빼 두었습니다.**

### ⑤ 카톡 QR (선택)
오픈채팅 QR 이미지를 `images/kakao-qr.png`로 저장한 뒤, `contact/index.html`의 QR 블록 주석을 풀면 됩니다.

## 4. 자주 하는 수정은 어디를 고치나

| 바꾸고 싶은 것 | 고칠 곳 |
|---|---|
| 색·글자 크기·여백 | `assets/css/ondo.css` 맨 위 `:root` 토큰 |
| 카카오톡 링크 | 모든 `.html`의 `open.kakao.com` + `assets/js/ondo.js`의 `KAKAO` |
| 요금 | `pricing/index.html`, 그리고 각 서비스 페이지의 요금 섹션 |
| 상단 메뉴·푸터 | 모든 `.html`에 같은 코드가 들어 있습니다 (아래 5번 참고) |
| 상단 공지 배너 | `index.html`의 `<div class="notice">` |
| 작업물 카드 | `work/index.html`의 `.works` 안 카드들 |

### 작업물(포트폴리오) 추가·수정
지금 걸려 있는 사이트는 다섯 개이고, **모두 실제 첫 화면 캡처가 미리보기로 들어가 있습니다.**

| 이름 | 주소 | 분류 | 미리보기 |
|---|---|---|---|
| 세이프클린ENG | safeclean.ondoco.workers.dev | 온도 웹 · 시공/설비 | `images/work/safeclean.webp` |
| 개묘한여행 | gaemyo-travel.vercel.app | 온도 웹 · 개인 브랜딩 | `images/work/gaemyo.webp` |
| 커리어전략연구소 | career-lab.ondoco.workers.dev | 온도 웹 · 전문가 브랜딩 | `images/work/career-lab.webp` |
| 지글의 주린이 가이드 | ziggle-stock.vercel.app | 온도 AI · 결과물 | `images/work/ziggle-stock.webp` |
| 지글의 그물망 매매법 | ziggle-3x.vercel.app | 온도 AI · 결과물 | `images/work/ziggle-3x.webp` |

노출 위치는 분류에 따라 자동으로 갈립니다.

| 페이지 | 보이는 것 |
|---|---|
| 메인 · 작업물 | 5개 전부 |
| 온도 웹 | 온도 웹 3개 |
| 온도 AI | 온도 AI 2개 |

한 곳만 고치면 어긋나니 `_tools/_frag.py` 아래쪽 `PORTFOLIO` 목록을 고치고
생성 스크립트를 다시 돌리는 쪽이 안전합니다.

#### 새 작업물 추가하는 순서
1. 사이트 첫 화면을 캡처합니다 (PC 기준, 가로 1400px 이상 권장).
2. **1000 × 512px (약 1.95:1)** 로 맞춰 WebP로 저장 → `images/work/<이름>.webp`
   (다른 비율이면 카드 안에서 위쪽 기준으로 잘려 보입니다. 앱처럼 화면이 좁으면 가운데만 잘라내세요)
3. `_tools/_frag.py`의 `PORTFOLIO`에 한 줄 추가합니다. 인자 순서는
   `(파일이름, 강조색, 주소, 표시할도메인, 이름, 분류, 설명, [태그], 서비스태그, 이미지대체텍스트)`
4. `_tools`에서 생성 스크립트를 다시 돌리면 세 페이지에 한 번에 반영됩니다.

업종별 구조 예시 카드(`work/index.html` 아래쪽)에 데모가 생기면
`<span class="work-soon">데모 준비 중</span>` 을
`<a class="work-link" href="주소" target="_blank" rel="noopener">데모 보기 →</a>` 로 바꾸시면 됩니다.

## 5. 메뉴·푸터를 한 번에 바꾸려면

정적 사이트라 상단 메뉴와 푸터 코드가 7개 파일에 똑같이 들어 있습니다.
하나만 고치면 나머지가 안 바뀌니, **전체 찾아 바꾸기**를 쓰시거나
`_tools/` 안의 생성 스크립트를 고쳐서 다시 만드시면 됩니다.

```bash
cd _tools
for f in _pages.py _p_web.py _p_clip.py _p_ai.py _p_rest.py _p_contact.py; do python3 "$f"; done
```
스크립트는 어디서 실행하든 **사이트 루트에 HTML을 덮어씁니다.**
손으로 고친 내용이 있으면 사라지니, 다시 만들기 전에 백업해 두세요.

## 6. 가격에 대한 메모

| 서비스 | 사이트 표기 |
|---|---|
| 온도 웹 | 베이직 5~8만 / 스탠다드 10~15만 / 프리미엄 20만~ |
| 온도 클립 | **30초 1편 20만 / 3편 54만(편당 18만) / 월 4편 68만(편당 17만)** |
| 온도 AI | 결과물 8~12만 / ＋전략 15~18만 / ＋강의 25만~ |

- 전 페이지 **부가세 별도** 표기입니다.
- 온도 클립은 "30초당 20만원" 기준으로 잡았습니다. 3편·월 관리는 편당 금액을 10%·15%씩
  낮춘 **제안값**이라 판매 전에 확인해 주세요. 길이 초과는 "30초당 20만원 기준 협의"로 써 두었습니다.
- 온도 AI 3단 구성 금액도 **제안값**입니다. 크몽 등 채널별로 다른 가격을 쓰실 거면
  이 사이트 표기와 채널 표기가 어긋나지 않게 맞춰 주세요.
- 묶음 할인은 "온도 웹 + 온도 클립 → 클립 금액 10% 할인"으로 통일해 두었습니다.
  (`web/index.html`, `clip/index.html`, `pricing/index.html` 세 곳)

### 가격을 고칠 때 손대야 하는 곳
한 곳만 고치면 다른 데가 안 맞으니, 아래를 함께 보세요.

| 값 | 파일 |
|---|---|
| 카드·요약 금액 | `index.html` (히어로 카드 3장 + 서비스 섹션 + 비교표) |
| 서비스별 상세 | `web/` `clip/` `ai/` 각 페이지의 헤더 지표 · 요금 섹션 |
| 통합 요금표 | `pricing/index.html` |
| 검색엔진용 구조화 데이터 | 각 페이지 `<head>` 안 `application/ld+json` |

## 8. 사이트에서 지킨 원칙

- 없는 실적·리뷰·고객사를 만들지 않았습니다. 실제로 배포된 세 사이트만 캡처와 함께 걸었고,
  나머지 업종 카드는 **“데모 준비 중”**으로 적혀 있습니다. 온도 클립·온도 AI는 아직 공개 사례가 없다고 명시했습니다.
- 검색 상위 노출, 숏폼 조회수, 취업 합격을 **보장한다고 쓰지 않았습니다.**
- 온도 AI는 “대신 만들어 준다”가 아니라 **함께 만들고 설명까지 넘긴다**로 서술했고,
  이력서에 사실과 다르게 쓰라고 권하지 않는다는 문장을 명시해 두었습니다.
